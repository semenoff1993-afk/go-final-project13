# Go Final Project 13 (Yandex Practicum)

Это веб-сервер для приложения-планировщика задач (To-Do List). Проект реализует полноценный REST API для управления задачами, вычисления дат по сложным правилам повторения и хранения данных в локальной базе SQLite.

## Выполненные задания со звёздочкой (Advanced)
В проекте реализованы **все** задания повышенной сложности:
1. Поддержка переменной окружения `TODO_DBFILE` для указания пути к базе данных.
2. Продвинутые правила повторения задач:
   - `w` — по дням недели;
   - `m` — по дням месяца.
3. Аутентификация по JWT токену (переменная окружения `TODO_PASSWORD`).
4. Деплой через Docker: написан `Dockerfile` для создания образа.
